# Решись Авиа — Сервис динамического ценообразования авиабилетов

Веб-приложение для анализа пассажиропотока, моделирования сценариев спроса и оптимизации доходности авиарейсов на основе квантильных ML-прогнозов.

**Автор:** Сафонов Валерий Евгеньевич  
**Турнир:** «Решись», трек «Технологии», продвинутый тур (Кейс: Динамическое ценообразование авиабилетов, Блок 3: Разработка)

---

## Описание проекта

В современных авиаперевозках статические тарифы приводят либо к недозагрузке бортов при завышенных ценах, либо к потере маржинальности при избыточном ажиотажном спросе. 

Сервис решает задачу оперативного ценообразования для коммерческого отдела авиакомпании:
1. Позволяет менеджеру выбрать маршрут и дату вылета через календарный интерфейс.
2. Мгновенно пересчитывает спрос («желают») и фактические продажи («купят») с учётом физической вместимости самолёта и чувствительности пассажиров к цене.
3. Рассчитывает финансовые метрики: выручку, чистую прибыль за вычетом затрат на обслуживание и процент загрузки борта (load factor).
4. Строит интерактивную диаграмму распределения спроса по 9 квантилям (от пессимистичного 0.1 до оптимистичного 0.9) с отображением лимита мест на борту.
5. Предоставляет сценарную таблицу с рекомендованной математически оптимальной ценой для каждого сценария.

## Архитектура системы

Приложение спроектировано по гибридной архитектуре, объединяющей микросервисный бэкенд и независимый фронтенд:

```
┌─────────────────────────────────────────────────────────────┐
│                       Frontend (SPA)                        │
│   Vanilla JS (ES6+) • Material Design 3 Dark • Chart.js     │
└──────────────┬───────────────────────────────┬──────────────┘
               │                               │
    (Локальный запуск / Docker)         (Vercel / Netlify)
               │                               │
               ▼                               ▼
┌───────────────────────────────┐  ┌──────────────────────────┐
│       Backend REST API        │  │   Static Cloud Client    │
│    Python 3 (http.server)     │  │  Автономный пересчёт     │
│   SQLite База данных (users)  │  │  через dataset.json      │
│   Хэширование SHA-256         │  │  и Web Storage           │
└───────────────────────────────┘  └──────────────────────────┘
```

1. **Серверная часть (Backend REST API):**
   - Написана на чистом Python 3 с использованием стандартных библиотек (`http.server`, `sqlite3`, `hashlib`, `json`).
   - Реализует REST API:
     - `GET /api/routes` — список направлений и их базовых параметров.
     - `GET /api/dates?route=...` — доступные даты вылета.
     - `POST /api/calculate` — расчёт спроса, продаж, выручки и прибыли рейса.
     - `POST /api/register` и `POST /api/login` — регистрация и авторизация пользователей с сохранением хэша паролей в SQLite.
2. **Клиентская часть (Frontend SPA):**
   - Тёмная тема Material Design 3 (высокая информационная плотность, отсутствие визуального шума).
   - Интерактивный график на базе автономной библиотеки Chart.js (квантили спроса 0.1–0.9 + пунктирная линия вместимости ВС).
   - Встроенный fallback: при размещении на статических платформах (Vercel, Netlify) приложение автоматически считывает `dataset.json` и производит расчёты прямо на клиенте с нулевой задержкой.

## Стек технологий

- **Backend:** Python 3, SQLite 3, встроенный HTTP-сервер.
- **Frontend:** HTML5, CSS3 (CSS Custom Properties, Flexbox, CSS Grid), Vanilla JavaScript (ES6+), Chart.js.
- **Контейнеризация:** Docker, Docker Compose.
- **Хостинг:** Vercel, Netlify.

## Варианты запуска

### Вариант 1. Облачный хостинг (Vercel)
Сервис оптимизирован для мгновенного развёртывания на Vercel (в репозитории настроен `vercel.json`):
https://reshis-airline.vercel.app/
- Доступен по публичной ссылке без необходимости локальной установки зависимостей.
- Работает на всех устройствах (десктоп, планшет, мобайл).

### Вариант 2. Docker / Docker Compose (Бэкенд + БД)
Запуск полного стека в изолированном контейнере:
```bash
docker compose up --build
```
или стандартным Docker CLI:
```bash
docker build -t reshis-airline .
docker run -p 8000:8000 reshis-airline
```
После запуска откройте в браузере: `http://localhost:8000`

### Вариант 3. Локальный запуск на Python
Для работы требуется только стандартный интерпретатор Python 3 (сторонние библиотеки `pip` не требуются):
```bash
python3 app.py
```
Сервер будет доступен по адресу `http://localhost:8000`.
